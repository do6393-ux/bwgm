# 부원여자중학교 정보교사 포털

정보교사 한 명이 수업·담임·정보 업무·교무실 정보를 한곳에서 관리하는 웹 포털입니다.
React + Vite + Tailwind 로 만들었고, 서버 코드는 없이 **Firebase(Auth, Firestore)** 만 사용합니다.

## 화면 구성

상단 탭 4개가 각각 다른 테마를 씁니다.

| 탭 | 누가 보나 | 기능 |
|---|---|---|
| **정보 수업** | 누구나 (학생 포함) | 작은 탭 5개, 학생에게는 앞의 3개만 (주소 `#lessons`·`#homework`·`#timer`·`#picker` 로 바로 열림). **홈**: 오늘 한눈에(공지사항 최근 3개 · 지금 낼 과제 · 최근 올라온 자료), 수업 도구(외부 링크) / **단원별 수업 자료실**: 제목·내용 검색 (제목에서 찾은 자료 먼저, 내용에서 찾은 자료는 찾은 부분 한 줄), 비공개 전환 / **과제**: 과제 게시·제출 / **수업 타이머**(로그인한 교사만): 분·초 직접 입력, 전체 화면, 다른 탭을 봐도 계속 돌고 끝나면 울림 / **발표자 뽑기**(로그인한 교사만): 명단 없이 반·인원만 골라 번호로 뽑기, 애니메이션 2가지(번호판 반짝·슬롯머신) 중 선택, 한 번에 1~4명, 결석 빼기(그날만), 중복 없이 뽑기, 전체 화면. 기록은 그 브라우저에만 저장 ([src/lib/picker.js](src/lib/picker.js)) |
| **내 학급** | 로그인한 교사 | 비상연락망, 자리배치(셔플·제외 학생·HWPX 출력), 청소구역(구역·조 추가/삭제/이름 변경, 끌어서 배정 옮기기), 행발·세특 문장 조립기 |
| **정보 업무** | 관리자 + 관리자가 허용한 교사 | 작은 탭 3개. **업무 카드**: 업무 칸반 대시보드, 업무별 상세 매뉴얼 / **달력**: 업무 일정 / **기자재 대여**: 기자재 대여 장부. 종류(태블릿·노트북…)와 번호를 직접 등록하고 고칠 수 있다(한 줄에 한 대, 엑셀 붙여 넣기, 번호로 채우기). 여러 대를 한 번에 빌려주고 일부만 반납할 수 있다. 반납 날짜는 정하지 않고(학교를 옮기거나 원할 때 반납), 반납할 때 반납 일시와 메모(구성품 확인 등)를 남긴다. 지난 기록은 눌러서 고치거나 지울 수 있고, 수리 중 표시가 있다 ([src/lib/equipment.js](src/lib/equipment.js)) |
| **교무실** | 로그인한 교사 | "오늘 한눈에" 카드(오늘 내 수업·급식·정보 업무 마감·과제 마감), 컴시간 시간표(교사별·학급별)와 변동 감지, NEIS 급식 |

- 로그인하지 않은 방문자(학생)는 "정보 수업" 탭만 볼 수 있습니다.
- 교사가 로그인하면 첫 화면은 **교무실(시간표)** 입니다.
- 휴대폰에서는 헤더가 2줄(로고·설정 / 탭 4개)로 줄고, 교무실은 교사 시간표가 맨 위에 와서 스크롤 없이 1~7교시가 보입니다.

## 디자인 구조

탭마다 분위기는 다르지만 코드는 같은 이름을 씁니다. 분위기는 **[src/index.css](src/index.css)** 의 탭별 블록만 고치면 바뀝니다.

- **색·모서리**: `<html data-theme="class|homeroom|work|office">`(App.jsx 가 전환)에 따라 CSS 변수가 바뀝니다.
  코드에서는 `bg-surface`, `text-ink-muted`, `border-line`, `text-accent`, `rounded-dialog` 같은 이름만 씁니다. 새 색이 필요하면 `tailwind.config.js` 에 이름을 넣고 네 블록에 값을 채웁니다.
- **움직임**: 같은 `ui-enter`(탭·카드 등장), `ui-fade`(모달 뒷배경), `ui-pop`(모달·알림)을 쓰되, 속도·이동 거리는 탭마다 다릅니다(`--m-dur`, `--m-shift` …). 교무실은 빠르고 짧게, 내 학급은 느리고 부드럽게. 목록 카드는 `style={{ "--i": 번호 }}` 로 차례대로 나타나고, 운영체제의 "동작 줄이기" 설정이면 모두 꺼집니다.
- **불러오는 중**: Firestore 응답이 오기 전에는 "없음" 대신 [Skeleton](src/components/ui/Skeleton.jsx) 자리 표시를 보여 줍니다. 실제 항목과 같은 크기라 화면이 밀리지 않습니다. 읽기가 실패해도 스켈레톤이 남지 않도록 오류 콜백에서도 "불러옴"으로 바꿉니다.
- **알림창**: 브라우저 기본 `alert`/`confirm` 은 쓰지 않습니다. `const { confirm, alert, toast } = useDialog()` ([DialogProvider](src/components/ui/DialogProvider.jsx))를 씁니다. 삭제 확인은 `confirm(msg, { danger: true, confirmText })` 로 "취소"에 먼저 포커스가 갑니다.

## 권한 구조

실제 접근 통제는 화면이 아니라 **[firestore.rules](firestore.rules)** 가 합니다. 화면의 숨김은 편의일 뿐입니다.

- **관리자**: `do6393@ice.go.kr` 한 명. 교사 계정 추가·삭제, 정보 업무 접근.
- **교사**: 관리자 + `teachers/{이메일}` 문서가 있는 사람. 헤더의 `teachers` 화면에서 관리자가 추가합니다.
- **정보 업무 허용**: `teachers/{이메일}.canWork === true` 인 교사. 같은 화면에서 교사별로 켜고 끕니다. 열람·수정 모두 가능합니다.
- **그 외(학생·외부인)**: 공지·수업 자료 읽기와 과제 제출(쓰기)만 가능합니다.

관리자 이메일을 바꾸려면 [src/lib/admin.js](src/lib/admin.js) 와 [firestore.rules](firestore.rules) 의 `isAdmin()` 을 **둘 다** 고치세요.

## Firebase 설정

1. **Authentication** → 로그인 방법에서 이메일/비밀번호를 켭니다. 포털에서 교사 계정을 만들려면 계정 생성(sign-up)도 허용 상태여야 합니다. 외부인이 계정을 만들어도 `teachers` 허용 목록에 없으면 데이터에는 접근할 수 없습니다.
2. **Firestore** → 규칙 탭에 [firestore.rules](firestore.rules) 내용을 통째로 붙여넣고 **게시**합니다. (이 저장소에는 `firebase.json` 이 없어서 CLI 배포 설정은 되어 있지 않습니다.)
3. 규칙을 고칠 때마다 다시 게시해야 적용됩니다.

게시 후 점검:
- 시크릿 창: "정보 수업" 탭만 보이고, 공지·자료가 읽히며, 과제 제출이 되는지. 제출 목록은 보이지 않아야 합니다.
- 일반 교사: 정보 업무 탭이 잠겨 있고 `teachers` 버튼이 없는지. 관리자가 허용하면 탭이 열리는지.
- 관리자: 내 학급 / 정보 업무 / 교무실 / `teachers` 버튼이 모두 보이는지.

### 주요 컬렉션

| 컬렉션 | 용도 | 읽기 / 쓰기 |
|---|---|---|
| `notices`, `lessons` | 공지, 수업 자료 | 공개 / 교사 |
| `homework` (+ `submissions`, `roster`) | 과제와 학생 제출물 | 과제·roster 공개, 제출물 원본은 교사 / 제출(create)은 누구나 |
| `homework_settings` | `classes`: 반·인원, `marks`: 교사가 매긴 "내용 부족" 표시 | 교사 |

## 컴시간 시간표 동기화

`timetable_schedules` 는 포털이 쓰지 않고 **읽기만** 합니다. 월~금 오전 7시 30분(KST)에 이 저장소의
GitHub Actions([.github/workflows/comcigan-sync.yml](.github/workflows/comcigan-sync.yml))가
[scripts/comcigan/sync-comcigan.cjs](scripts/comcigan/sync-comcigan.cjs) 를 돌려 `firebase-admin`(서비스 계정)으로 기록합니다.
Admin SDK 는 보안 규칙을 거치지 않으므로 규칙과 무관하게 동작합니다.

- 저장소 시크릿 `FIREBASE_SERVICE_ACCOUNT` 에 서비스 계정 JSON 이 있어야 합니다.
- Actions 탭에서 직접 실행할 때 "저장하지 않고 가져온 내용만 확인"을 켜면 Firestore 에 쓰지 않고 로그만 남깁니다.
- 컴시간 페이지는 `parse-comcigan` 으로 읽습니다. 내부 파일(`dist/loader.js`)을 쓰므로 버전을 고정해 두었고, 올릴 때는 확인 실행부터 하세요.
- 읽어 온 수업이 학급당 10칸 미만이면 기존 데이터를 지우지 않도록 저장하지 않고 실패로 끝납니다.
- 교시 시작 시각은 `timetable_schedules/meta_periods` 에 `{ times: ["09:00", ...] }` 로 둡니다. "오늘 한눈에" 카드의 "지금" 표시가 이것을 씁니다 (없으면 표시만 빠집니다).
- 동기화는 평일 아침에만 돌기 때문에, "오늘 한눈에" 카드는 문서의 `updatedAt` 으로 `this`/`next` 중 오늘(주말이면 다음 월요일)이 든 주를 고릅니다 ([src/lib/todayBrief.js](src/lib/todayBrief.js) `pickWeekKey`).

포털의 "데이터 연동 상태"는 실제로 읽어 온 결과를 보여줍니다 (정상 / 일부만 수신 / 없음 / 실패).

## 기기 간 동기화

연락처·자리배치·청소·누적 기록은 **Firestore 를 기준**으로 읽고, 이 기기의 localStorage 는 캐시·오프라인 대비로만
씁니다. 이 기기에 더 최근에 저장된 사본(저장 실패, 오프라인 편집)이 있으면 그것을 우선합니다.
자세한 내용은 [src/lib/syncedStorage.js](src/lib/syncedStorage.js) 의 주석과 테스트를 보세요.

- **2차원 배열은 그대로 저장되지 않습니다.** Firestore 는 "배열 안의 배열"을 거부합니다. 자리 표(줄 × 칸)와 기피 짝은
  화면에서는 2차원 배열로 쓰고, 서버에 올릴 때만 [src/lib/gridCodec.js](src/lib/gridCodec.js) 로 한 겹 풀어
  (`{cells:[…]}`, `{a, b}`) 저장합니다. 읽을 때는 예전 모양도 받아 줍니다. (예전에는 이 오류가 콘솔에만 남아서 자리배치·청소구역이
  그 기기에만 저장됐습니다. 지금은 서버 저장에 실패하면 알림이 뜹니다.)
- **이 기기에만 남은 데이터는 열어 볼 때 서버로 올라갑니다.** 서버 문서가 없거나 이 기기 사본이 더 최근이면
  `loadSynced` 의 `onLocalNewer` 로 올립니다 (서버를 정상적으로 읽은 경우에만).

## 청소구역

- **구역·조 편집**: "구역·조 편집"을 누르면 구역과 조를 추가·삭제하고 구역 이름을 바꿀 수 있습니다 (구역 최대 20개, 조 최대 10개).
  배정된 학생이 있는 구역·조를 지울 때는 확인창이 뜹니다. 조는 번호(01조, 02조…)로만 표시되어 지우면 뒤의 조 번호가 당겨집니다.
- **끌어서 옮기기**: 구역 왼쪽의 ⠿ 손잡이를 끌어 다른 구역에 놓으면 그 구역의 모든 조 배정이 함께 옮겨지고,
  사이에 있던 구역의 배정은 사라지지 않고 한 칸씩 밀립니다 (맨 위를 맨 아래로 끌면 전체가 한 칸씩 위로 회전).
  구역 이름은 그대로 두고 배정만 움직입니다. 마우스·터치·키보드(손잡이에서 ↑ ↓) 모두 되고, 표가 화면보다 길면 가장자리에서 자동 스크롤됩니다.
- **HWPX 양식**: `{{C_행_열}}`(예: `{{C_1_1}}` = 첫 구역·01조 학생)에 더해 `{{A_행}}`(예: `{{A_1}}` = 첫 구역 이름)을 쓸 수 있습니다.
  표에 없는 칸(지운 구역·조)의 태그는 빈칸으로 나옵니다.
- **양식 받기**: 자리배치·청소구역 화면의 "양식 받기" 버튼이 기본 양식을 내려받게 해 줍니다. 받은 양식을 한글에서 고쳐 "HWPX 올리기"로 올리면 됩니다.
  양식 파일은 `public/templates/` 에 있고 **저장소와 사이트를 여는 누구나 받을 수 있으므로, 양식 안의 이름은 실제 학생 이름이 아닌 예시 이름이어야 합니다.**
  양식을 고쳤다면 같은 이름(`seating-template.hwpx`, `cleaning-template.hwpx`)으로 덮어쓰고, 파일 정보의 작성자 이름은 비워 두세요.
  저장소 루트에 둔 `*.hwpx` 는 `.gitignore`(`/*.hwpx`)로 올라가지 않습니다.
- 편집 규칙은 [src/lib/cleaningModel.js](src/lib/cleaningModel.js) 에 모아 두었고 테스트가 있습니다. 예전에 저장된 표(구역 이름 없음)는
  기본 구역 이름 6개와 함께 그대로 읽습니다.

## 알아둘 점

- 수업 자료의 "비공개(hide)"는 학생에게 보이는 목록과 상세 화면에서 가리는 기능입니다. `lessons` 는 공개 읽기라서
  자료 ID 를 아는 사람이 Firestore 를 직접 읽는 것까지 막지는 못합니다. 민감한 내용은 올리지 마세요.
- 자리배치의 기피 조합 입력은 학생에게 화면을 보여줄 때를 대비해 일부러 숨겨져 있습니다. 교탁 라벨을 **세 번** 누르면 열립니다.
